# Rural Forms

Web App tạo Form Thống Kê với Cross Link GĐV/QLKV/CH — giống Google Forms nhưng tích hợp dữ liệu Rural.

## 🚀 Link truy cập
👉 **[Mở Rural Forms](https://ruralwcm.github.io/rural-forms/)** 👈

## Tính năng
- 📋 Tạo form với 7 loại câu hỏi (Trả lời ngắn, Đoạn văn, Trắc nghiệm, Checkboxes, Dropdown, Ngày, Số)
- 🔗 Cross Link GĐV → QLKV → CH từ Storeslist (realtime)
- 📊 Dashboard quản lý forms & responses tập trung
- 📥 Export CSV

## Hướng dẫn
1. Mở link trên → Dashboard
2. Tạo Form mới → Thêm câu hỏi → Bật Cross Link
3. Copy link form → Gửi cho QLKV điền
4. Responses tự động về Sheet
